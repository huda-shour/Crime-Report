# Crime-Report
A database management system developed to manage crime reports,
residents, police officers, and response actions.

## Features
- Manage resident information
- Record crime reports
- Manage police responses
- Database operations using SQL

## Technologies
- SQL
- PHP
- MySQL
- Database Design (CDM/PDM)

## Project Components
- SQL database scripts
- PHP interface
- Conceptual Data Model (CDM)
- Physical Data Model (PDM)
